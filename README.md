# Inkwell Blog App

A responsive blog application interface built with plain HTML and inline CSS. No build step and no dependencies.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home (desktop) |
| `home-tablet.html` | Home (tablet layout) |
| `home-mobile.html` | Home (mobile layout) |
| `login.html` | Login |
| `register.html` | Register |
| `dashboard.html` | Dashboard |
| `create-blog.html` | Create Blog |

## Run locally

Open `index.html` in a browser. The pages link to each other.

## Host on GitHub Pages

Repository **Settings > Pages**, choose the `main` branch and the root folder, then save.

## Notes

- Fonts (Bricolage Grotesque and Newsreader) load from Google Fonts.
- Forms and buttons are static UI. Authentication and publishing are not wired to a backend.
